# Vida Digital

Web estática preparada para subir a Internet.

## Archivos
- `index.html` — página principal
- `styles.css` — diseño responsive
- `script.js` — interacciones
- `README.md` — instrucciones

## Cómo verla
Abre `index.html` en Chrome, Edge, Safari o Firefox.

## Cómo publicarla gratis
### GitHub Pages
1. Crea una cuenta en GitHub.
2. Crea un repositorio nuevo.
3. Sube estos 4 archivos.
4. En Settings → Pages, activa Pages desde la rama principal.
5. GitHub te dará una dirección pública.

### Netlify
1. Crea una cuenta.
2. Arrastra la carpeta del proyecto a Netlify Drop.
3. Netlify publicará la web automáticamente.

### Vercel
También puedes importar el repositorio de GitHub en Vercel.

## Para monetizarla de verdad
Esta versión es una base funcional. Antes de lanzar:
- sustituye el formulario demo por Brevo/Mailchimp/ConvertKit;
- crea páginas legales y política de cookies adaptadas a tu caso;
- añade contenido original;
- configura Google Search Console y analítica;
- crea enlaces de afiliación solo con programas que acepten tu web;
- añade un CMS si quieres publicar artículos desde un panel.

No hay ingresos garantizados: el tráfico, el contenido, la confianza y la estrategia comercial son los que determinarán si el proyecto genera dinero.
