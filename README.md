# Vida Digital — web estática

Proyecto editorial en español sobre IA, productividad, dinero digital, privacidad y herramientas.

## Publicación
Sube todos los archivos a la raíz del repositorio de GitHub Pages y usa `main` + `/(root)`.

## Antes de monetizar
- Sustituye los marcadores de recursos por enlaces reales y, si corresponde, enlaces de afiliado.
- Conecta un proveedor de newsletter si quieres captar suscriptores.
- Añade analítica solo después de configurar correctamente consentimiento y privacidad según tu caso.
- Completa las páginas de privacidad, cookies y aviso legal con datos reales y asesoramiento profesional si procede.
